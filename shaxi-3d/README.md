# 沙溪 · 旧时游

以云南沙溪和参考照片为灵感的可步行三维古镇。本地运行，场景布局经过游戏化调整，不是地理测绘复刻。

## 单文件版本（直接打开）

项目源码位于 `static/shaxi-3d/`，构建成品为本目录下的 `shaxi-3d.html`。直接双击 HTML 即可运行，也可以将这一个文件放在静态网站上；无需 Node.js 服务、CDN 或同目录素材。浏览器需要支持 WebGL 2 并开启硬件加速。首次打开需解码内嵌高清材质和天空，可能稍有等待。

修改源码后，在本目录执行：

```sh
npm ci
npm run build:single
```

构建会将 React、Three.js、页面样式、21 张 PBR 贴图、HDR 天空及材质清单合并为一个 HTML，自动验证无外部脚本分块与样式资源。成品不会覆盖 `static/index.html`。提交源码时包含本目录及其中的 `shaxi-3d.html`；`node_modules` 和构建缓存已忽略，无需提交。

`npm run build` 保留原有服务端构建；需要直接用浏览器打开时使用 `npm run build:single`。

## 启动

Node.js 22.13 或更新版本，浏览器需要 WebGL 2 与硬件加速。

```sh
npm install
npm run dev
```

打开 http://localhost:3000/ 。材质、HDR 天空和人物参考图片均随项目保存，运行时不请求第三方素材服务。首次进入会等待素材加载完成。

## 操作

- WASD／方向键行走，Shift 快走。
- 空格起跳；空中逐次按下可接二、三段直立旋身，落稳后恢复。
- 拖动画面环顾，滚轮调整距离；右侧「看人物」进入正面近景。
- V 切换鸟瞰／跟随，H 隐藏界面，Esc 恢复。
- 靠近人物、茶席或风铃后按 E／点击互动按钮。
- 敞开门口可直接步行进入；三段轻功可以登上阳台、屋顶。
- 手机使用方向按钮及轻功按钮；地点列表默认收起，展开后换行显示。
- 午后／薄暮、晴日／山雾／细雨可切换，微风影响树叶、草叶、长发和飘带。

## 当前场景

200 × 210 的探索范围，16 个主要区域，地图共 37 处标注（包含 21 间开放房屋）。此次增加 34 栋建筑，72 处房屋屋顶可落脚，71 栋带室内的建筑均可进入，包括茶室、客栈、书斋、食肆和工坊。客栈带床铺，其余室内设桌椅、茶具、陈列架；所有开放房屋设阳台。

60 位街头人物（行人、玩耍儿童、挑担货郎），加上 17 位摊贩和 21 位室内掌柜，共 98 位。主角与人、墙、屋面、天花板之间存在高度相关的碰撞。人物会走动、摆手招呼或做角色动作。

地面、石材、木材、墙面、瓦面和树皮使用实景 PBR 色彩／法线／粗糙度贴图。HDR 天空同时提供环境反射与照明，地面有实体草丛、石块与缝隙，树叶和草叶随风轻摆。

主角使用纯几何建模的头部、鼻梁、脸颊、眼窝、眼睛、眉毛和嘴唇，调整了头身比例；当前角色不加载任何照片面部贴图。这是程序建模的三维角色，不是写实扫描模型。


## 素材来源

- [Poly Haven](https://polyhaven.com/) 的素材采用 [CC0](https://polyhaven.com/license)。各项来源记录在 `public/assets/pbr/manifest.json` 和 `sky-source.json`。Powered by Poly Haven。
- 人物原图由用户提供，保存在 `public/assets/character/reference-face.png`，文件未做图像编辑。
- 面部拓扑和通用深度源于 [MediaPipe canonical_face_model.obj](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/modules/face_geometry/data/canonical_face_model.obj)，Apache 2.0，许可证保存在人物素材目录。特征数据保存在 `lib/shaxi/face-data.json`，无需在浏览器运行面部识别模型。

## 代码

- `app/page.tsx`：中文界面及交互。
- `lib/shaxi/world.ts`：建筑、室内、植被和几何合批。
- `lib/shaxi/surfaces.ts`：本地 PBR／HDR／人物纹理加载。
- `lib/shaxi/reference-face.ts`、`face-data.json`：参考图面部重建。
- `lib/shaxi/heroine.ts`：主角建模及动作。
- `lib/shaxi/engine.ts`：渲染、输入、相机、人物调度。
- `lib/shaxi/navigation.ts`：碰撞、跳跃、桥面与屋顶。
- `lib/shaxi/atmosphere.ts`：天空、天气与雨。

当前交付为本地项目，没有 Git 提交或线上部署。

## 山水、建筑与坐姿更新

- 屋檐与墙体间新增封闭阁楼墙、山墙和木构支撑，修正瓦片半圆面的朝向；门窗补充木框、门板与门环。
- 远山改为连续山脊地形；4K HDR 天空中的太阳方向与场景光源一致，天空跟随相机，树叶增加叶脉、斑驳及正反面差异。
- 河水使用双层流动法线、平面倒影与折射，替换整体上下起伏和漂浮矩形高光；包含岸边细碎水纹。
- 地图显示完整道路及 37 个编号标注，可点击前往，也可在地点列表按编号查找。
- R 或右上角「坐下」原地盘坐，再按起身；行走会起身，坐着按空格先起身，下一次再起跳。空中不能坐下。坐姿包含衣裙收拢、手脚调整与恢复过渡。

新增检查覆盖坐下起身后的身高和地面接触、面部坐标一致性、水流相位及屋顶接缝。没有进行浏览器视觉或性能验收。

## 完整地图与市井生活

- 点击小地图或按 M 打开完整地图：显示道路、建筑、地点名称及当前位置；支持缩放、定位自己、搜索地点，点击名称或侧栏条目传送。地图包含 87 处地点。
- 全部 71 栋有室内的建筑设开放门洞，71 处室内落点及入口通过了连通检查；景观亭和城门保持原有开放结构。先前封闭的房屋改为独立墙体，部分建筑设前后通门。
- 保留原有 98 位人物，增加多种街头及室内人物，包括地摊摊主、买家、掌柜、小二、食客、房客及放烟花的街坊，另有 6 只小狗。新增人物按距离显示，近处可见摆手、夹菜、端盘走动等动作。
- 点击「夜色」进入夜间，室内暖灯亮起、街坊燃放烟花；系统开启减少动态效果时关闭烟花。
- 远山增加地形采样和绿色层次。人物脸部已经停止使用参考图贴图，原始素材文件仅作历史保留。

本轮验证包含所有建筑门洞与落点、新增角色种类、狗的数量、纯几何面部及烟花昼夜开关；未执行浏览器视觉验收。不进行 Git commit。

## 不降低画质的运行优化

- 静态建筑碰撞使用空间索引，只筛选当前位置与移动路径附近的障碍物；保留门洞、天花板、屋檐、镜头避障和三段轻功的原有判定。
- 人物碰撞数据复用，通过实时位置读取保持路人、店小二、小狗的碰撞更新，减少逐帧创建数组与对象。
- 镜头避障复用临时向量。人物数量、动画更新频率、贴图、阴影、水面反射折射和画面分辨率保持不变。
- `npm test` 包含索引与全量扫描的随机轨迹对照，以及使用索引的完整古镇回归。可运行 `node --experimental-strip-types scripts/benchmark-collision.mts` 比较实际古镇的碰撞计算耗时；该数字不代表浏览器 FPS 或 GPU 性能。
