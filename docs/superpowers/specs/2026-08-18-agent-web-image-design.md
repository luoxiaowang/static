# Agent 联网查询与图片生成设计

## 目标

在现有只读 Agent 助手中复用 AgnesAI Key，自动识别普通问答、联网查询和图片生成三类意图。聊天记录、搜索结果和生成图片仅保留在当前页面，不写入 IndexedDB。

## 路由策略

新增独立意图路由模块，输出 `chat`、`web` 或 `image`：

- 明确包含“生成图片、画一张、制作海报、设计封面”等表达时路由到 `image`。
- 明确包含“最新、今天、目前、新闻、价格、天气、搜索、查询”等实时表达时路由到 `web`。
- 工作台数据总结、Todo 查询和普通咨询路由到 `chat`。
- 图片意图优先于联网意图，避免“生成一张今天的天气海报”被错误路由为纯搜索。
- 规则无法确定时，调用 AgnesAI 做三分类；分类失败则降级到普通聊天。

## API 设计

### 普通问答

继续使用 `POST /v1/chat/completions` 和 `agnes-2.5-flash`，保留完整工作台上下文和本机时间基准。

### 联网查询

使用 `POST /v1/responses`，模型为 `agnes-2.5-flash`，工具为 `web_search_preview`。解析 `output[].content[]` 中的 `output_text`，同时收集 `annotations` 中的标题与 URL。请求最多等待 90 秒；失败时给出可重试提示，不伪造来源，不自动改走模型记忆回答实时问题。

### 图片生成

使用 `POST /v1/images/generations`，模型为 `agnes-image-2.1-flash`，默认尺寸 `1024x1024`，通过 `extra_body.response_format = "url"` 获取图片地址。解析 `data[0].url`，若仅返回 `b64_json` 则转换为 Data URL。请求最多等待 120 秒。

## 界面与数据结构

内存消息扩展为三类：

- 文本消息：角色、正文。
- 联网消息：正文、来源列表。
- 图片消息：图片 URL、原始提示词。

对话区展示：

- 联网回答下方展示去重后的来源链接。
- 图片以响应式预览卡展示，提供“下载图片”和“重新生成”。
- 思考状态根据路由显示“正在分析工作台数据”“正在联网查询”或“正在生成图片”。
- “停止”按钮中止当前聊天、搜索或图片请求。

## 错误处理

- 意图分类失败：降级普通聊天。
- 联网超时或无来源：明确提示联网查询失败，允许重试。
- 图片接口无有效 URL/Base64：提示生成失败，保留原提示词以便重试。
- 401/403、429、5xx 沿用现有中文错误映射，不展示 API Key 或请求头。
- 新请求开始前中止上一请求，避免响应乱序。
