# 个人工作台效率与 AI 能力扩展设计

日期：2026-08-18

## 1. 目标

在保留纯静态部署、直接双击 HTML、IndexedDB 本地存储和 Element Plus 中后台视觉的基础上，增强通知状态、工作周倒计时、拟真沙漏、Todo 排序、番茄钟、灵感与碎碎念输入体验，并新增收藏夹与基于 AgnesAI 的全站 Agent 助手。

## 2. 约束与决策

- 页面保持纯静态形态，不增加服务端。
- AgnesAI 使用 `agnes-2.5-flash` 与 OpenAI 兼容的 `/v1/chat/completions` 接口。
- API Key 按用户明确要求由静态应用直接使用；不在界面、备份、错误日志或测试输出中展示。
- Agent 只读咨询，不直接新增、修改或删除工作台数据。
- Agent 聊天记录仅保存在当前页面内存中，刷新后清空。
- 不自动执行 Git 提交。

## 3. 数据模型

### 3.1 Todo

新增 `priority` 字段，取值为 `high`、`medium`、`low`。旧记录缺少该字段时按 `medium` 处理。

排序顺序固定为：

1. 未完成记录在前，已完成记录在后。
2. 优先级按高、中、低排列。
3. 同优先级按到期时间由近到远排列；无到期时间排在有到期时间之后。
4. 其余情况按创建时间排列。

### 3.2 设置与番茄钟

设置表新增通知授权记录，用于解决授权成功后刷新仍显示“请申请权限”的问题。页面加载时同时读取浏览器真实 `Notification.permission` 与应用授权记录；真实权限优先，记录用于保持正确文案和授权状态。

番茄钟运行状态保存到设置表，包含预设时长、剩余时长、运行状态和目标结束时间。刷新后根据目标结束时间恢复真实进度。

### 3.3 收藏夹

新增 `favorites` 数据表，记录：

- `id`
- `url`
- `domain`
- `title`
- `summary`
- `outline`
- `recognitionStatus`
- `createdAt`
- `updatedAt`

收藏夹纳入导出、合并导入、覆盖还原与清空全部数据。

## 4. 页面与交互设计

### 4.1 通知

授权成功后刷新页面仍显示已授权状态，申请按钮同步禁用或显示“已授权”。只有浏览器真实权限失效时才重新提示申请。

### 4.2 工作周倒计时

本周倒计时以周一 00:00 为开始、周五 24:00（周六 00:00）为结束。周六和周日显示“本周工作时间已结束”，进度保持 100%，下周一重新开始。

### 4.3 拟真时间沙漏

放大沙漏主体和剩余时间文本，增强玻璃厚度、边缘折射、高光、金属立柱、木质纹理、沙面、沙丘、落沙颗粒、投影和层次。动画继续受 `prefers-reduced-motion` 控制。

### 4.4 Todo

新建与编辑表单增加高、中、低优先级。列表增加“全部 Todo / 当前日期”切换：全部模式忽略日期筛选、显示每条记录所属日期，并继续采用统一排序规则；切回后恢复当前日期视图。

### 4.5 番茄钟

倒计时页面顶部增加番茄钟模块，提供 30 分钟与 1 小时预设，以及开始、暂停、继续、重置操作。同一时间仅运行一个番茄钟。结束时复用浏览器通知、页面提醒和提示音。

### 4.6 创意灵感与碎碎念

两类输入器悬浮在内容区底部，使用圆角蓝色操作栏、半透明背景、阴影和安全区适配。灵感按本地日期分组，组内按时间倒序，并继续支持全部、未实现、已实现筛选。

### 4.7 颜色

普通按钮统一为中后台蓝色体系。删除、永久清空和过期告警保留红色，成功状态保留绿色，警告状态保留橙色。

## 5. 收藏夹 AI 识别

收藏夹入口包含 URL、标题、摘要和 Markdown 大纲字段。输入 URL 后点击“AI 识别”，应用直接调用 AgnesAI，要求模型读取 URL 并输出标题、简洁摘要和分层大纲。

识别成功后自动填充字段，用户可编辑再保存。识别失败或模型明确无法访问网页时，不猜测内容、不自动保存，只保留 URL 并允许用户手动填写其他字段。

收藏卡片展示域名、标题、摘要和可展开大纲，并支持访问原网页、编辑和二次确认删除。

## 6. Agent 助手

左侧新增 Agent 助手菜单。每次发送问题时，应用实时读取 Todo、普通倒计时、番茄钟状态、灵感、碎碎念和收藏夹，构建结构化上下文后调用 AgnesAI。

Agent 支持当前页面内的多轮对话、发送中状态、重新生成、错误提示和清空会话。Agent 仅提供检索、总结、规划与建议，不写入业务数据。

为控制请求大小，上下文设置字符上限，优先保留未完成 Todo、未到期倒计时和最新记录；发生截断时在上下文中明确标记。

## 7. 模块边界

现有 Vue 页面保持入口职责，新增独立纯逻辑模块：

- Todo 排序与筛选
- 工作周区间计算
- 番茄钟状态机
- AgnesAI 客户端与响应解析
- 收藏识别字段解析
- Agent 全站上下文构建与截断

IndexedDB 层负责数据库版本升级、收藏夹表和设置持久化；备份模块负责新增数据的兼容导入导出。

## 8. 错误处理

- API 请求提供并发保护，避免重复点击。
- 401、429、网络失败、CORS、响应为空和响应格式错误显示可理解的提示。
- 日志不输出授权请求头、API Key 或完整敏感上下文。
- 收藏识别失败保留手动编辑能力。
- AI 功能失败不影响任何本地功能。

## 9. 测试与验收

- 通知授权成功后刷新仍显示已授权。
- 工作周结束时间为周五 24:00，周末状态正确。
- 沙漏主体和数字清晰，浅色、深色、桌面与移动端均无布局问题。
- Todo 按完成状态、优先级和到期时间排序；全部与日期模式可切换。
- 番茄钟支持 30 分钟、1 小时、暂停、继续、重置和刷新恢复。
- 灵感按日聚合，两个输入器正确悬浮并适配移动端。
- 收藏识别成功时填充内容，失败时允许手填，收藏数据可备份恢复。
- Agent 上下文覆盖全部数据类型，聊天不持久化且不能操作数据。
- API 错误不泄露 Key 或请求头。
- 全量单测、构建、语法检查、HTML 检查和浏览器控制台检查通过。
