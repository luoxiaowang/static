# 个人工作台 Element Plus 重构设计

## 1. 重构目标

将现有原生静态个人工作台重构为专业、克制的中后台管理界面。使用 Vue 3 与 Element Plus 的浏览器 CDN 构建真实组件体验，同时保留直接双击打开和静态服务器托管两种使用方式。

本次重构不改变 IndexedDB 数据结构和四项核心业务能力，只调整技术呈现层、视觉系统、布局、删除交互和倒计时沙漏效果。

## 2. 技术方案

- Vue 固定使用 `3.5.40` 的浏览器 global production 构建。
- Element Plus 固定使用 `2.14.3` 的浏览器全量构建与 CSS。
- 使用 Element Plus 简体中文语言包。
- CDN 地址固定具体版本，不使用 `latest`。
- 页面继续使用经典 `<script>` 标签，不依赖 ES Modules，因此可通过 `file://` 直接打开。
- CDN 资源加载失败时显示独立错误页，说明需要联网并提供刷新入口，禁止空白页。
- IndexedDB 数据库名称、版本、对象仓库和字段保持不变，已有数据无需迁移。
- 现有备份格式、合并导入和覆盖还原保持兼容。

CDN 运行模式意味着直接双击页面时也必须联网加载 Vue 与 Element Plus。用户已明确接受此约束，以换取更小的本地项目体积。

## 3. 整体布局

### 3.1 桌面端

页面采用标准管理后台布局：

- 左侧固定竖向导航，展开宽度约 220px，折叠宽度约 72px。
- 导航顶部展示工作台标识、名称和简短日期文案。
- 中部依次展示 Todo、倒计时、创意灵感、碎碎念四个菜单。
- 菜单使用图标、中文名称和明确选中态。
- 导航底部独立放置主题切换、设置入口和折叠按钮。
- 右侧为主内容区，顶部展示当前页面标题、辅助说明和主要新增按钮。
- 主内容区充分使用桌面空间，不设置过窄的阅读栏。

### 3.2 移动端

- 固定侧栏隐藏，顶部显示菜单按钮和当前页面名称。
- 菜单按钮打开 Element Plus Drawer。
- 内容卡片切换为单列。
- 底部快捷输入区适配安全区域，不遮挡内容。

## 4. 视觉系统

整体使用 Element Plus 的标准中后台风格，不采用纯黑、霓虹、科技光效或明显纸张纹理。

- 主色以 Element Plus 蓝为基础，仅用于主要操作、选中态和重点数字。
- 页面背景使用柔和浅灰，卡片为白色，搭配细边框和轻量阴影。
- 卡片圆角统一为 12px，输入框和按钮保持 Element Plus 默认比例。
- 深色模式采用深灰蓝背景与中性灰边框，避免纯黑高对比。
- 页面标题 24px，区块标题 16px，正文 14px，辅助信息 12px。
- 列表保持适度紧凑，表单与卡片之间保留清晰留白。
- 使用统一的 8px 间距基准，控制模块之间的纵向节奏。
- 操作反馈统一使用 `ElMessage`，表单错误使用 Element Plus 校验提示。

## 5. Element Plus 组件映射

- 页面布局：`el-container`、`el-aside`、`el-main`、`el-menu`。
- 日期与时间：`el-date-picker`。
- 新增与编辑：`el-dialog`、`el-form`、`el-input`、`el-switch`。
- 设置中心：`el-drawer`、`el-select`、`el-upload` 或隐藏文件选择器。
- 状态展示：`el-tag`、`el-progress`、`el-badge`。
- 列表与空状态：`el-card`、`el-empty`、`el-timeline`。
- 危险操作：`el-dialog` 与输入校验。
- 操作反馈：`ElMessage`。

## 6. 删除交互

所有普通记录删除不再弹出确认框，采用按钮原地二次点击：

1. 第一次点击“删除”后，当前按钮变为红色“再次确认”。
2. 用户在 5 秒内第二次点击时立即删除。
3. 超过 5 秒未点击，按钮自动恢复为“删除”。
4. 用户切换菜单、点击页面其他区域或点击另一条记录的删除按钮时，原确认状态取消。
5. Todo、自定义倒计时、创意灵感和碎碎念使用同一套交互。

只有“清空全部数据”保留危险操作弹窗。弹窗要求完整输入“确认删除”，只有文本完全一致时确认按钮才可点击。清空成功后重新初始化页面状态。

## 8. SVG 沙漏设计

沙漏使用内联 SVG 绘制，避免远程图片资源：

- 上下横梁使用木质渐变，左右支柱使用金属渐变。
- 玻璃容器包含轮廓、透明填充、柔和高光和阴影。
- 上半部分沙量随剩余比例降低，并呈现水平沙面。
- 中部使用连续细沙流和轻微颗粒闪烁动画。
- 下半部分沙堆随已流逝比例升高，顶部呈弧形或锥形。
- 本日、本周、本月、本年、人生使用统一结构和不同辅助色。
- 卡片显示剩余天、时、分、秒及已流逝百分比。
- SVG 结构只初始化一次，每秒仅更新沙量、文字和 CSS 变量，避免动画重置。
- 系统启用 `prefers-reduced-motion: reduce` 时停止沙流和颗粒动画。

## 9. 数据流与兼容

- Vue 应用启动前先确认 Vue 与 Element Plus 全局变量可用。
- 应用挂载后初始化 IndexedDB，再加载设置和业务记录。
- 所有增删改仍通过现有 IndexedDB 仓储层完成。
- Vue 响应式状态保存当前菜单、侧栏折叠、对话框、筛选和删除确认状态。
- 写入成功后刷新对应集合与设置中的数据统计。
- 备份格式版本保持为 1，不改变已有导出文件结构。

## 10. 异常处理

- CDN 加载失败：显示资源加载失败页面和重新加载按钮。
- IndexedDB 初始化失败：显示无法安全保存数据的错误提示，阻止写入操作。
- 日期和时间输入非法：使用 Element Plus 表单校验阻止提交。
- 通知权限被拒绝：继续使用页面提醒和可选提示音。
- 导入文件非法：不修改现有数据，并通过 `ElMessage.error` 显示原因。
- 覆盖导入事务失败：保持原数据不变。

- Vue、Element Plus 和中文语言包使用固定版本 CDN。
- 页面可以直接双击打开，也可以通过静态服务器访问。
- 已有 IndexedDB 数据和现有 JSON 备份仍可使用。
- Todo、倒计时、灵感和碎碎念均完成 Element Plus 组件化重构。
- 普通删除严格使用 5 秒内二次点击确认，不再出现弹窗。
- 清空全部数据必须输入“确认删除”。
- 五个沙漏具备真实容器、动态沙量、沙流和减少动态效果适配。
- 浅色、深色、桌面和移动端视觉均保持专业中后台风格。

- 自动测试、脚本语法检查和浏览器交互验收全部通过。
