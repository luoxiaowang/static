# 个人工作台产品设计

## 1. 产品目标

构建一个完全离线、仅在浏览器本地运行的个人工作台，用于管理每日 Todo、倒计时、创意灵感和碎碎念。应用不依赖网络，不上传任何个人数据，并提供完整的数据导入、导出、备份和还原能力。

## 2. 范围与原则

- 使用原生 HTML、CSS、JavaScript 实现，产物放在独立的 `workbench/` 目录。
- 保留四个主功能 Tab：Todo、倒计时、创意灵感、碎碎念。
- 工具类功能统一收纳到右上角“设置”入口，不新增设置 Tab。
- 所有数据使用 IndexedDB 持久化，页面刷新或浏览器重启后继续保留。
- 不使用 CDN、远程字体、远程图片、埋点或任何网络接口。
- 视觉参考 Element UI，但不引入 Element UI 或其他第三方运行时依赖。
- 第一版不提供账号、多设备同步、云备份或协作能力。

## 3. 信息架构

### 3.1 页面头部

头部包含工作台标题、四个主 Tab、当前日期摘要和设置按钮。设置按钮位于右上角，打开侧边抽屉。

### 3.2 设置抽屉

设置抽屉集中提供：

- 主题：浅色、深色、跟随系统。
- 人生倒计时：首次填写出生日期，之后可修改；默认寿命为 85 岁。
- 提醒设置：浏览器通知权限状态、申请权限入口、提示音开关。
- 数据管理：导出全部数据、合并导入、覆盖还原、清空全部数据。
- 数据摘要：各类记录数量、最近一次导出时间。

覆盖还原和清空数据必须二次确认。覆盖还原前自动导出当前数据，避免误覆盖后无法恢复。

## 4. 功能设计

### 4.1 Todo

Todo 以所属日期分组，默认定位到今天，并支持切换日期。每条 Todo 包含：

- 唯一 ID
- 标题
- 可选备注
- 所属日期
- 可选截止日期时间
- 完成状态与完成时间
- 创建时间与更新时间

状态计算规则：

- 已完成：显示绿色“已完成”。
- 未完成且当前时间已超过截止时间：显示红色“已过期”。
- 未完成且距截止时间不超过 24 小时：显示黄色“即将到期”。
- 未填写截止时间：仅按所属日期展示，不计算到期状态。
- 其余未完成事项：显示默认“进行中”状态。

日期组内按未完成优先、截止时间升序排列；无截止时间的事项排在有截止时间事项之后。支持新增、编辑、勾选完成、恢复未完成和删除。删除前需要确认。

### 4.2 倒计时

#### 指定时间倒计时

用户可创建多个倒计时，每条包含名称、目标日期时间、创建时间、是否已提醒和提醒时间。未到期项目实时显示剩余天、时、分、秒；到期后显示“已到期”。

到期时按以下顺序提醒：

1. 浏览器通知，前提是用户已授权且浏览器允许。
2. 页面内弹窗，始终作为可见兜底。
3. 本地生成的提示音，用户可在设置中关闭。

普通静态页面只有在页面保持打开时才能可靠准时提醒。重新打开页面时，应用检查尚未提醒但已经到期的记录并补充提醒。

#### 关键日期倒计时

固定展示五个沙漏卡片：

- 本日：当前时间到当天 24:00。
- 本周：以周一为一周起点，到下周一 00:00。
- 本月：到下月第一天 00:00。
- 本年：到下一年 1 月 1 日 00:00。
- 人生：从出生日期到 85 岁生日；未设置生日时显示填写引导。

每张卡片显示剩余时间、已流逝百分比和纯 CSS 沙漏流沙动画。系统启用“减少动态效果”时关闭持续动画。人生倒计时到达终点后显示已超出时间，不显示负数。

### 4.3 创意灵感

页面底部提供悬浮输入区，支持点击发送和键盘快捷提交。每条灵感包含内容、实现状态、创建时间、实现时间和更新时间。

列表按创建时间倒序排列，支持按全部、未实现、已实现筛选。用户可以编辑内容、切换实现状态和删除记录；删除前需要确认。

### 4.4 碎碎念

页面底部提供悬浮输入区，用于快速记录心得和日常想法。记录按自然日分组，日期组按日期倒序排列，同一天内按具体时间倒序排列。

每条记录显示完整日期时间，支持编辑和删除；删除前需要确认。

## 5. 数据设计

IndexedDB 数据库使用带版本号的结构，包含以下对象仓库：

- `todos`：Todo 记录。
- `timers`：指定时间倒计时。
- `ideas`：创意灵感。
- `thoughts`：碎碎念。
- `settings`：主题、生日、提示音、最近导出时间等设置。

所有业务数据使用字符串 ID，时间统一存储为 ISO 8601 字符串，展示时按浏览器本地时区格式化。数据访问集中在独立存储模块，页面功能模块不直接操作 IndexedDB。

## 6. 导入与导出

导出文件为 UTF-8 JSON，包含：

- 应用标识
- 数据格式版本
- 导出时间
- Todo、倒计时、灵感、碎碎念和设置数据

导入前依次校验 JSON 语法、应用标识、格式版本、集合类型和必要字段。校验失败时拒绝写入并给出中文原因。

支持两种导入模式：

- 合并导入：按 ID 去重；ID 相同时以导入文件内容为准，不同 ID 追加。
- 覆盖还原：先自动下载当前完整备份，再清空并写入导入文件。

导入写入过程使用单次事务；任意写入失败则整体回滚，避免只恢复部分数据。

## 7. 视觉与响应式

应用采用 Element UI 风格的浅灰背景、白色卡片、细边框、适中圆角、蓝色主按钮和轻量阴影。深色模式采用深灰蓝背景和柔和边框，避免纯黑高对比。

桌面端使用居中内容区；窄屏下 Tab 支持横向滚动，表单转为纵向布局，底部输入区适配设备安全区域。状态同时使用颜色、文字和图标表达，避免只依赖颜色。

所有交互控件提供可见焦点、中文辅助标签和合理的键盘操作。空列表显示对应空状态和新增引导。

## 8. 异常与边界处理

- IndexedDB 不可用或初始化失败：阻止误操作并明确提示无法安全保存数据。
- 通知权限被拒绝：继续使用页面弹窗和提示音，不反复申请权限。
- 导入文件非法：不修改现有数据，显示具体校验原因。
- 浏览器数据被清理：应用无法恢复，因此设置页持续提示定期导出备份。
- 多个页面同时打开：监听本地数据库变更信号并提示刷新，避免用户误以为页面数据已同步。
- 日期切换、夏令时和跨年：所有倒计时目标由本地日历边界动态计算，不使用固定天数近似。

## 10. 验收与测试

### 功能验收

- 四个 Tab 可正常切换，刷新后保留当前主题和全部业务数据。
- Todo 的完成、即将到期、过期状态计算准确。
- 指定时间倒计时可新增、恢复、到期和补充提醒。
- 五个关键日期倒计时随当前时间更新，人生倒计时依赖生日设置。
- 灵感和碎碎念支持新增、编辑、状态切换或分组、删除。
- 设置抽屉可完成主题、生日、通知和数据管理操作。
- 导出文件可重新合并导入或覆盖还原，非法文件不会污染已有数据。

### 兼容性与体验验收

- 在当前版本的 Chrome、Edge、Safari 中完成基础手动验证。
- 桌面宽屏和常见手机宽度下无横向页面溢出。
- 深色模式下文字、边框、状态标签和弹窗均清晰可读。
- 页面不产生任何网络请求。
- 开启系统“减少动态效果”后，沙漏不执行持续动画。

## 11. 明确限制

- 数据仅存在当前浏览器和当前浏览器配置中，不会跨设备同步。
- 浏览器完全关闭或系统休眠时，静态页面无法保证准时发送倒计时通知。
- 清理浏览器站点数据会删除 IndexedDB 数据，恢复依赖用户先前导出的 JSON 备份。
