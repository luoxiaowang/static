从前端开发，到 Agent 工程

AI Agent 学习路线六个阶段，从第一次调用到工程落地

用一套中文教程作为主线，每阶段补充专项资料，并完成一个小项目。沿用 TypeScript 与 Node.js，把接口、状态管理和交互经验迁移到 Agent 开发。

中文优先两份英文专项文档每阶段都有实践目标
用一个「前端研发助手」贯穿学习

生成用例 → 查询规范 → 读取代码 → 编排任务 → 自动评估

01
基础入门

大模型基础与 API 调用

理解提示词、上下文和模型调用，完成第一个 AI 功能。

中文 · 必读

LLM Cookbook：面向开发者的 LLM 入门教程 ↗

先读「面向开发者的 Prompt Engineering」，再读「搭建基于 ChatGPT 的问答系统」。掌握清晰指令、示例、输出格式和问答流程。

官方中文 · 必做

DeepSeek：首次调用 API ↗

理解请求结构、消息角色、API Key 和返回数据，用 Node.js 跑通一次调用。

官方英文 · 补充

AI SDK：Node.js 入门 ↗

沿用 TypeScript 技术栈，学习模型接入、流式响应和会话消息。可以配合浏览器翻译。

阅读顺序提示词教程 → API 调用 → 流式对话 → 问答系统设计。

学习提醒先掌握输出校验、请求失败处理和用户取消。示例代码与依赖版本配套，API 参数以提供方当前文档为准。

动手练习

做一个「需求描述 → 测试用例」页面，支持生成、取消和错误提示。

02
工具调用

理解 Agent，掌握执行循环

让模型选择工具，由程序校验并执行，再将结果交回模型。

中文 · 主线

Hello-Agents：从零开始构建智能体 ↗

按顺序读第一章《初识智能体》、第三章《大语言模型基础》、第四章《智能体经典范式构建》、第七章《构建你的 Agent 框架》。

中文 · 必读

精读：第四章 · 智能体经典范式构建 ↗

重点理解 ReAct，再看任务规划和反思。追踪模型输出、程序执行、工具结果以及下一轮决策之间的关系。

阅读顺序理解 Agent → 手写工具循环 → 增加停止条件 → 再学框架。

学习提醒历史介绍可略读，多框架对比留到后面。不要让工具失败或重复调用形成无限循环。

动手练习

做一个能搜索代码、读取文件、分析错误的助手，并限制最大工具调用次数。

03
知识检索

RAG、知识库与上下文工程

让 Agent 找到并正确使用项目资料，回答能够追溯来源。

中文 · 必读

All-in-RAG：RAG 技术全栈指南 ↗

依次学习第一章 RAG 简介与四步构建、第二章数据加载与文本分块、第三章向量嵌入与数据库、第四章混合检索与查询构建、第六章系统评估。

中文 · 补充

Hello-Agents：记忆与上下文 ↗

阅读第八章《记忆与检索》、第九章《上下文工程》，把检索结果、历史对话与任务状态联系起来。

阅读顺序基础检索 → 文档分块 → 向量检索 → 混合检索 → 效果评估。

学习提醒第一轮可以跳过多模态、知识图谱与复杂索引优化。区分「没有搜到资料」和「有资料但回答错误」。

动手练习

把组件库文档做成问答助手，回答附出处，并测试文档中不存在答案的情况。

04
系统编排

MCP 与复杂任务编排

接入外部系统，管理多步骤任务的状态、暂停与恢复。

中文翻译 · 必读

微软 MCP 入门课程：简体中文版 ↗

学习核心概念、创建 Server 和 Client、工具接入与调试。课程有 JavaScript / TypeScript 示例；中文版为自动翻译。

官方英文 · 补充

LangGraph：JavaScript 官方文档 ↗

学习 State（状态）、Node（节点）、Edge（边），再看持久化、人工介入与执行恢复。

阅读顺序写一个 MCP 工具 → 学习状态图 → 实现暂停与恢复。

学习提醒MCP 用于标准化接入工具与资源；LangGraph 用于编排有状态的执行流程。重试与恢复时要避免重复写入。

动手练习

把文档搜索封装成 MCP 工具，再做「读取需求 → 生成用例 → 人工确认 → 生成报告」流程。

05
工程落地

评估与工程可靠性

用数据判断效果，定位失败，并验证每次改动是否带来提升。

中文 · 必读

Hello-Agents：第十二章 · 智能体性能评估 ↗

学习成功条件、评估样例、指标、基准测试与评估框架，理解评估结果的适用范围。

中文 · 补充

All-in-RAG：系统评估 ↗

阅读第六章，分别评估检索与生成，找到影响回答质量的具体环节。

中文翻译 · 补充

微软 MCP：安全、测试与部署 ↗

选择安全、测试和部署相关内容，补齐工具服务的工程实践。

阅读顺序定义成功 → 建立样例集 → 记录执行过程 → 回归比较。

学习提醒给项目补上日志、耗时与成本记录、超时重试和权限校验。评估应从早期就开始，这一阶段将它系统化。

动手练习

整理 30 个真实问题，记录成功与失败原因；每次改提示词或换模型，都重新运行并比较。

06
深入选修

综合项目与模型原理

根据实际目标选择深入方向，把能力沉淀成一个完整作品。

中文 · 应用方向

Hello-Agents：综合项目 ↗

选第十三章《智能旅行助手》或第十四章《自动化深度研究智能体》，完整拆解任务分工、信息传递与结果验证。

中文 · 原理方向

Happy-LLM：从零开始构建大模型 ↗

先读第二章 Transformer、第三章预训练语言模型、第四章大语言模型，再决定是否进行训练实践。

阅读顺序完成应用项目 → 用评估定位瓶颈 → 按需求深入原理或训练。

学习提醒前端转 Agent 应用工程师，建议先完成应用路线；模型训练、LoRA 和强化学习在有明确需求时再学。

动手练习

选择一个真实场景，交付可运行的 Agent、使用说明、评估结果与失败案例分析。

从今天开始

先把第一个小功能做出来

  1. 读 LLM Cookbook 的提示词工程部分，试着改写一份需求生成提示词。
  2. 按照 DeepSeek 中文文档，用 Node.js 跑通模型调用。
  3. 接入熟悉的 Vue 或 React 页面，完成测试用例生成、取消与错误提示。
  4. 保存正常和异常输入，作为后续工具调用、检索和评估的第一批样例。

阅读方式：中文教程中的示例多使用 Python，可先理解原理，再用 TypeScript 实现。资料可以免费阅读，运行示例时的模型 API 可能需要付费。模型与框架持续更新，代码和参数请对照当前官方文档。
