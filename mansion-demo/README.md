# 山隐 · 现代中式园林住宅

扩建版：现代乡村园林住宅，现包含西翼会客厅、天台、地下室、街道集市与河岸。入口是 **index.html**，双击即可在支持 WebGL 2 的浏览器中离线运行。Three.js、HDR 环境、模型及贴图全部内嵌，文件约 53 MiB，首次打开需要解码模型。

## 操作

| 功能 | 操作 |
| --- | --- |
| 鸟瞰 / 漫游（默认庭院漫游） | 页面按钮或 B |
| 鸟瞰旋转 / 缩放 / 平移 | 鼠标拖动 / 滚轮 / WASD |
| 查看室内布局 | 鸟瞰时点击“隐藏屋顶” |
| 行走 / 奔跑 | WASD 或方向键 / 按住 Shift |
| 跳跃 | 空格，或“跳跃”按钮 |
| 坐下 / 躺下 / 起身 | C / L / R，或页面按钮；再次按 C 或 L 也可起身 |
| 第一人称 / 第三人称 / 鸟瞰 | V |
| 场景互动 | 靠近后按 E 或点击提示 |
| 日夜、声音与画质 | 右上角按钮 |
| 回到入口 | “返回庭院” |

行走速度为 4.8 米/秒，奔跑 8 米/秒；跳跃约 1.3 米高。靠近沙发、床或泳池躺椅时，坐卧会吸附到对应家具；远离家具时可在原地坐卧。按 R 恢复行走。

鸟瞰独立于角色移动：可环绕整个院落、平移和缩放，隐藏屋顶后看到二层及两翼室内；二层楼板仍保留。

## 空间与功能

- 深色低坡金属屋面，白色实体墙与落地玻璃结合，内院草坪、石径、木格栅和茶亭。
- 左翼书房：书墙、电脑、键盘、笔记本电脑、阅读灯、壁炉与皮椅。
- 右翼客餐厅：柔化边缘的分块沙发、现代单椅、电视柜、完整餐桌摆设。
- 主宅厨房：岛台、吧凳、水槽与龙头、电磁炉、烤箱、油烟机、冰箱和咖啡机。
- 一楼移除卧床，改为起居客厅、电视与独立咖啡吧；二层保留主卧、儿童房及卫浴。
- 新增西翼会客厅，地面住宅占地增加约 110 平方米；庭院围合范围从约 53 × 44 米扩大到 66 × 50 米。
- 天台有茶桌座椅、圆形薄檐茶亭、秋千、花箱和可种植的小花圃。
- 地下室包含储物架、影音客厅与电视、KTV 麦克风和音箱、双桌电竞房。
- 庭院有花圃、结着桃子和橘子的果树；南门外是六个有摊主的集市摊位，再向前是河畔步道。
- 庭院茶席、花圃、鱼塘、锦鲤、乌龟、反射泳池与三张躺椅。
- 家人和两条小狗保持独立日常动画；阅读、喝茶、种花、喂鱼、摸狗等互动保留。

从庭院正中进入主宅，先沿入口内侧横向走到右边，1.5 米宽的楼梯通往二层，较原 3.2 米宽缩窄约 53%，并移到东侧墙边。书房、客厅与主宅在靠后的侧面门洞相连。

## 画面升级

实际下载并使用了 Poly Haven 的六种 CC0 模型：树木、蕨类、灌木、盆栽、现代单椅与茶几。树木和植被经 Blender 简化后使用实例渲染。

新增 HDR 环境照明、接触阴影（GTAO）、柔和泛光、池面实时反射和细小波纹；材质使用颜色、法线和粗糙度贴图。贴图按空间尺寸铺设，玻璃不再投射整面不透明阴影。

这是实时三维 Demo，人物仍为程序化角色，日常行为采用预设循环。没有声称达到参考图片的离线路径追踪渲染质量。高画质较依赖 GPU，帧率不足时切换“画质：流畅”。

## 文件与重建

- `index.html`：独立离线成品，单独复制也可运行。
- `assets/mansion.blend`：更新后的完整 Blender 场景，含实例化树木、家具和贴图；为编辑快照，不包含网页交互逻辑。
- `assets/interior.blend` / `interior.glb`：原创壁炉和皮椅。
- `assets/model-sources.json`：新下载模型的来源与许可。
- `assets/texture-sources.json` / `environment-source.json`：贴图与 HDR 来源。
- `src/world.mjs` / `details.mjs` / `district.mjs`：建筑、园林及室内陈设。
- `src/navigation.mjs`：通行、统一楼梯尺寸和跳跃物理。
- `src/realism.mjs`：真实模型、HDR、反射与后期处理。
- `src/main.mjs` / `characters.mjs`：镜头、交互与人物。

```sh

npm test

npm run build
```

## 网页性能优化版

默认采用手动“流畅”模式；切换到“自动”后，根据持续帧率调节，短暂卡顿不会立刻切换。右上角按钮依次切换自动、流畅、均衡、精细；底部显示当前帧率。手动档位不会被自动覆盖。

| 设置 | 流畅 | 均衡 | 精细 |
| --- | --- | --- | --- |
| 最大像素倍率 | 0.85 | 1 | 1.25 |
| 阴影分辨率 | 1024 | 1536 | 2048 |
| 阴影更新间隔 | 200 ms | 100 ms | 66 ms |
| 泳池 | 环境反射 | 实时反射，最多约 6 次/秒 | 实时反射，最多约 12 次/秒 |
| 接触阴影与泛光 | 关闭 | 关闭 | 开启，接触阴影半分辨率 |

树木、灌木、盆栽和蕨类按距离切换三档网格，并按空间分区剔除视野外实例；近距离继续使用原模型。重复屋顶构件已合并，此前基础场景的静态绘制批次从 174 降至 51；扩建部分继续按材质合并，新增网格纳入批次数量测试。均衡/流畅模式直接渲染，避免无用后处理；隐藏标签页时停止渲染工作。

扩建前的树木单次几何提交预算：鸟瞰均衡档约从 370 万面降至 19 万面；庭院、书房和二层的代表性位置降低约 88%—91%。这些是几何预算计算，**不是实测 FPS 增幅**。详细数据见 `assets/runtime/performance-report.json`。

`assets/runtime/` 是从原模型生成的网页 LOD 副本，原始 GLB 和 Blender 编辑场景不变。重建原模型后执行 `npm run build:lod`，再生成 HTML。测试还覆盖自动画质滞后、手动档位、后台恢复、LOD 切换和索引完整性。本轮没有浏览器性能采样，实际帧率请以网页显示为准。


## 移动闪烁修正

- 草地表面降至木地板下方 5 厘米，消除同平面深度冲突；庭院底板与铺砖限制在室外范围。

- 37 项自动化测试通过，其中包含地面射线检查、LOD 临界移动与纹理过滤回归检查。未进行浏览器视觉验收。

## 扩建空间怎么走

- **天台**：一楼沿东侧窄楼梯向北上二楼，到北侧平台转向西边相邻的楼梯，再向南上天台。茶席靠西，小花圃靠东；靠近按 E 喝茶或种花。
- **地下室**：从庭院绕到住宅西侧，走到西侧下行楼梯，沿楼梯向北下到底部，再向东进入房间。储物与电竞区在北侧，KTV 与影音厅在南侧。
- **集市与河岸**：从南侧院门出去，沿街道向前走，两侧有鲜果、点心、花草摊位，尽头是河岸。
- **互动范围**：电视是本地绘制的风景屏幕，可切换色调；KTV 播放短合成示范伴奏；电竞房是设备与桌面演示，没有嵌入实际游戏或联网点歌。果树已有果实，尚未加入采收背包。

新增空间没有新增外部下载依赖。保留自动画质、植被 LOD、贴图过滤与防共面闪烁处理；地下室补光只在角色进入地下时启用。

## 立体导览、天气与车库更新

- 已取消物体上方的悬浮名称；地点名称保留在界面与导览地图内。
- 点击左下角的庭院导览，或顶部“导览地图”，打开可旋转、缩放的三维简化地图。按庭院与一楼、二楼、天台、地下室分层，点击金色标记或地点列表可直接传送，共 26 个落点。地图展开期间主场景暂停渲染，避免两套场景同时占用 GPU。
- 顶部天气菜单支持晴天、雨天、雪天、大风天，日夜可独立切换。下雪时屋顶、室外地面等朝上的暴露表面变白，切回其他天气恢复。大风时植被摆动并出现风线；雨雪为实时粒子演示，未实现积雪厚度物理与真实湿地反射。
- 西侧菜地缩小，增加朝南开门的车库，停放一辆不可驾驶的越野车；入口前的车道保持可通行。
- 天台改为圆形薄檐茶亭；天台与一楼院内各有一处秋千，走近按 C 坐上，按 R 起身。
- 夜间点光源亮度提高约 50%，同时提高环境补光和曝光。两翼屋顶改为圆角薄板、错层收边与悬浮檐口。

本轮新增测试覆盖全部传送点及其可离开性、天气往返切换、雨雪遮蔽高度、两处秋千配置。构建和静态资产校验通过；尚未执行浏览器实际交互与 GPU 着色器视觉验收。

## 春节与空间扩容版

- 开场直接进入庭院第三人称，默认固定流畅画质。
- 住宅、庭院及地下室使用统一的平面比例，长宽各扩大 √2 倍，面积翻倍，层高保持不变；主要沙发、座椅、桌子保留原尺寸。角色保持正常体型与 4.8 / 8 米每秒的步行 / 奔跑速度。
- 地下室楼梯底部增加入口门；庭院南侧增加宽双扇大门。靠近按 E 开关，关闭后阻挡通行，门口有人时不允许关门。默认打开。
- 地下室及车库范围禁止生成野生花草；围墙内外分开铺设草地与黄土地。
- 围墙灯、红灯笼、贴在门柱和门楣上的春联营造春节气氛；雪天显示院内两个雪人，切换其他天气隐藏。
- 展开地图后，地点采用房间、建筑、水池、树冠、圆亭等不同几何形状，并显示可点击的中文名称。
