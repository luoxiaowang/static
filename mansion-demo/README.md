# 山隐 · 现代中式园林住宅

移动端与渐进加载版。网页入口为 **index.html**，通过 HTTP 打开（例如 `http://127.0.0.1:8768/index.html`）。首屏只下载约 19 KiB HTML 和 755 KiB JavaScript，进入后再异步加载模型、贴图与 HDR；运行素材保留在 `assets/` 下。

需要双击离线使用时，运行 `npm run build` 后打开生成的 **offline.html**。它包含全部素材，体积约 51 MiB，不享受网页入口的网络首屏体积优化；该分发文件不纳入 Git。

| 功能 | 操作 |

行走速度为 4.8 米/秒，奔跑 8 米/秒；跳跃约 1.3 米高。靠近沙发、床或泳池躺椅时，坐卧会吸附到对应家具；远离家具时可在原地坐卧。按 R 恢复行走。

鸟瞰独立于角色移动：可环绕整个院落、平移和缩放，隐藏屋顶后看到二层及两翼室内；二层楼板仍保留。

## 画面升级

实际下载并使用了 Poly Haven 的六种 CC0 模型：树木、蕨类、灌木、盆栽、现代单椅与茶几。树木和植被经 Blender 简化后使用实例渲染。

新增 HDR 环境照明、接触阴影（GTAO）、柔和泛光、池面实时反射和细小波纹；材质使用颜色、法线和粗糙度贴图。贴图按空间尺寸铺设，玻璃不再投射整面不透明阴影。

这是实时三维 Demo，人物仍为程序化角色，日常行为采用预设循环。没有声称达到参考图片的离线路径追踪渲染质量。高画质较依赖 GPU，帧率不足时切换“画质：流畅”。

## 文件与重建

- `index.html` + `app.js` + `assets/`：轻量网页入口、脚本和按需素材，部署时一起复制。

- `assets/interior.blend` / `interior.glb`：原创壁炉和皮椅。
- `assets/model-sources.json`：新下载模型的来源与许可。
- `assets/texture-sources.json` / `environment-source.json`：贴图与 HDR 来源。
- `src/world.mjs` / `details.mjs` / `district.mjs`：建筑、园林及室内陈设。
- `src/navigation.mjs`：通行、统一楼梯尺寸和跳跃物理。
- `src/realism.mjs`：真实模型、HDR、反射与后期处理。
- `src/main.mjs` / `characters.mjs`：镜头、交互与人物。

## 网页性能优化版

默认采用手动“流畅”模式；切换到“自动”后，根据持续帧率调节，短暂卡顿不会立刻切换。右上角按钮依次切换自动、流畅、均衡、精细；底部显示当前帧率。手动档位不会被自动覆盖。

| 设置 | 流畅 | 均衡 | 精细 |
| --- | --- | --- | --- |
| 最大像素倍率 | 0.85 | 1 | 1.25 |
| 阴影分辨率 | 1024 | 1536 | 2048 |
| 阴影更新间隔 | 200 ms | 100 ms | 66 ms |
| 泳池 | 环境反射 | 实时反射，最多约 6 次/秒 | 实时反射，最多约 12 次/秒 |
| 接触阴影与泛光 | 关闭 | 关闭 | 开启，接触阴影半分辨率 |

树木、灌木、盆栽和蕨类按距离切换三档网格，并按空间分区剔除视野外实例；近距离继续使用原模型。重复屋顶构件已合并，此前基础场景的静态绘制批次从 174 降至 51；扩建部分继续按材质合并，新增网格纳入批次数量测试。均衡/流畅模式直接渲染，避免无用后处理；隐藏标签页时停止渲染工作。

扩建前的树木单次几何提交预算：鸟瞰均衡档约从 370 万面降至 19 万面；庭院、书房和二层的代表性位置降低约 88%—91%。这些是几何预算计算，**不是实测 FPS 增幅**。详细数据见 `assets/runtime/performance-report.json`。

`assets/runtime/` 是从原模型生成的网页 LOD 副本，原始 GLB 和 Blender 编辑场景不变。重建原模型后执行 `npm run build:lod`，再生成 HTML。测试还覆盖自动画质滞后、手动档位、后台恢复、LOD 切换和索引完整性。本轮没有浏览器性能采样，实际帧率请以网页显示为准。

## 移动端适配与首次进入优化

- 普通 PC 保持 52° 视场角与原跟随距离 5；手机和窄屏触控设备使用 68°、距离 7.5，使人物在屏幕中更小，同屏内容更多，角色碰撞体和世界比例不变。
- 移动端隐藏左侧文案模块与常驻小地图，保留顶部导览入口；工具栏可横向滑动，方向键与动作按钮适配安全区及横竖屏。
- 首屏只等待基础几何第一次渲染，重素材全部进入空闲时段队列，每次最多处理一项。室内家具、壁炉、植物按角色位置加载，表面纹理只在相应材质进入视野后请求；同类实例共享模型。
- 远处树木先用轻量轮廓占位，模型载入后替换。几何按房间与楼层分区，保留视锥剔除，未靠近地下入口时跳过地下几何。
- 默认流畅模式直接渲染，不创建接触阴影与泛光的离屏缓冲；精细模式才初始化这些后期资源。
- 素材 URL 带内容版本，浏览器可以复用缓存。某个素材失败不会遮挡页面或阻塞其他任务，点击素材状态可重试。
- `assets/runtime/startup-report.json` 记录 HTML、JS 和离线版的构建体积。没有把体积减少直接表述为实机耗时或 FPS 提升；本轮未做手机浏览器视觉验收与网络性能采样。

本机局域网手机预览可使用 `python3 -m http.server 8768 --bind 0.0.0.0`，然后在同一网络的手机访问电脑的局域网 IP 与端口；正式部署需上传完整网页目录。

### 移动端清晰度与摇杆

手机流畅模式渲染比例从 0.85 提高到 1.35，均衡 / 精细为 1.6 / 1.85（不超过设备像素比，画布最多约 240 万像素）。提高近处植被细节与地面纹理过滤，优先加载视野内材质细节；桌面画质参数保持原值。

### 家庭动线与家具布局调整

一楼沿东侧通道向北到楼梯起点，上楼后落在二层南侧公共平台。平台连通卧室走廊与第二段天台楼梯，无须穿过卫浴；卫浴原东侧门已封闭。同步反转踏步与扶手的升高方向，保留原楼板洞口。

主卧床头移到北墙，床头柜分列两边；东侧电视柜对着休闲沙发，跑步机留在西侧。儿童房榻榻米床头靠北墙，书架和低玩具柜分别靠西、东墙，阅读桌靠北窗，中间留作活动区，移除床后的置物架。一楼两处观影沙发朝向东侧电视，书房书柜靠西墙，西翼会客厅保留北侧电视与朝北沙发，地下影音厅和 KTV 保持相对布置；移除多余茶几和走廊单椅。

建筑窗玻璃、淋浴屏、阳台护栏及导入模型中的玻璃统一为烟灰色透明材质，保留透视，降低发白感。室内门按实际世界尺寸约束，阳台门宽约 1.2 米；庭院大门保留原尺寸。

回归包含卫浴关闭情况下从一楼经平台抵达两个卧室与阳台、天台往返、门框碰撞、沙发朝向及儿童活动区通道。当前仅完成代码与几何测试，未进行浏览器视觉验收。

### 现代墙面与加宽门洞

墙面采用暖白底色，不再叠加原灰色石膏颜色贴图，保留细微法线纹理。卧室、书房及地下影音区增加浅米色织纹墙纸；儿童房东侧为本地绘制的皮卡丘、精灵球主题墙布，其他区域增加浅木框山水画和植物画。纹理在本地 Canvas 生成，离线版同样可用，无外部图片请求。

按最新要求，室内门宽从约 1.05 米扩大至 2.1 米，阳台门从 1.2 米扩大至 2.4 米；高度保持 2.2 米，墙体开口、护栏开口和门扇碰撞一起更新。

### 二楼走道与儿童游乐阳台

二楼走道改为烟熏深木地板、暖白顶面、浅色几何织纹墙纸、黑框建筑照片墙和带灯木展示格，装饰避开房门与两段楼梯洞口。装饰贴图保留独立 UV，避免挂画与墙布被地面平铺逻辑重复采样。

楼梯旁东侧直接连通客餐厅屋顶，地面同为 3.6 米，无须绕过卧室。屋顶更换为平整儿童露台，外圈灰玻璃护栏，内设软垫、滑梯、沙池、踏步墩、玩具柜、陪护长椅和盆栽；滑梯作为静态设施参与碰撞，沙池提供亲子文字互动。导览地图可选择“儿童游乐阳台”。

回归验证楼梯平台—阳台—沙池往返、护栏阻挡、滑梯碰撞和地图落点。未进行浏览器视觉验收。
