# 丰巢武汉研发中心 · 1024 一起绽放

参考 `mansion-demo` 的 Three.js + 原生 JavaScript + esbuild 技术栈制作的独立互动场景。建筑与快递柜按提供的三张参考图进行风格化建模；所有模型、中文纹理和烟花都在本地生成，无 CDN、模型下载或后端依赖。

## 打开体验

直接双击 **`offline.html`** 即可。分享时只需要这一个文件。

也可以在本目录运行：

```sh
npm run serve
```

打开 `http://127.0.0.1:4175`。`index.html` 和 `app.js` 用于普通静态站点部署。

## 操作

| 操作 | 方式 |
| --- | --- |
| 开始 | 点击「和王金枝一起出发」，全程第三人称 |
| 移动 | WASD / 方向键；手机拖动左下角圆盘 |
| 转向 | 在场景中按住鼠标拖动；手机滑动右侧画面 |
| 场景视角 | 固定第三人称，柜机退出和烟花结束后恢复跟随镜头 |
| 快速找到互动点 | 下方「走向快递柜」「走向烟花」，人物会实际步行前往 |
| 停止自动行走 | 方向键 / WASD / Esc / 手机圆盘 |
| 附近交互 | E 或画面上的「开始操作」「点燃烟花」 |
| 退出柜机 | 「退出操作」或 Esc，恢复第三人称 |
| 音效 | 右上角开启，默认关闭 |

页面需现代浏览器与 WebGL 2。移动端已提供触控与竖屏布局，桌面大屏能看到更多建筑细节。

## 场景内容

- 浅色石材楼体、中央玻璃幕墙、入口雨棚、研发中心中文招牌、两侧配楼。
- 建筑左侧绿色丰巢快递柜，分格柜门、蜂巢装饰和可操作的屏幕。
- 门前树木、花坛、长椅、路灯和广场铺装。
- 主角王金枝，以及李萌、林福君、钟知慧、张凯、尹新月、艾山、邱菊；中文姓名标签、独立服饰与发型、步行和欢呼动画。
- 实时小地图、两项体验进度与步行导航。

## 互动流程

**快递柜**：走到屏幕前 → E / 开始操作 → 镜头推进到屏幕 → 服务界面。空调清洗、储物下单、存被开门、洗衣洗鞋、取快递、寄快递等全部 10 个服务入口均触发「1024 丰巢程序员节日快乐」和电子礼花。可返回服务首页再次体验，也可退出恢复第三人称。

**烟花**：靠近烟花桶 → 点燃 → 引线火花沿引线燃烧 → 8 人实际跑向各自的围圈位置 → 检查全员到齐 → 发射升空 → 转为夜景，彩色烟花与中文粒子祝福持续 **10 秒**，全员跳跃欢呼 → 返回原位并恢复白天和自由移动。可以重复点燃。

烟花期间镜头自动转向开阔天空，完整展示围圈与祝福。10 秒按页面可见时的真实时间计时；切到后台会暂停体验，避免错过庆祝。

## 开发与构建

```sh
npm ci
npm test
npm run build
npm run serve
```

在当前仓库中，构建脚本也能复用相邻 `mansion-demo/node_modules` 中已有的相同版本依赖，无需改动 mansion-demo。

- `src/config.mjs`：角色、场景位置、碰撞与时长。
- `src/architecture.mjs` / `landscape.mjs` / `locker.mjs`：建筑、广场与互动道具。
- `src/characters.mjs`：原创几何人物与骨骼动画。
- `src/controls.mjs` / `simulation.mjs`：移动、避障导航、集合状态机。
- `src/fireworks.mjs` / `particles.mjs`：升空、礼花和中文粒子祝福。
- `src/terminal.mjs` / `ui.mjs`：柜机交互与场景界面。
- `src/environment.mjs` / `audio.mjs`：昼夜过渡、光照与可选音效。
- `src/main.mjs`：场景装配和动画循环。
- `src/template.html` / `style.css`：中文界面与手机适配。
- `scripts/build.mjs`：输出网页版和完整离线 HTML。

静态模型按材质合批，烟花使用复用的粒子缓冲区。`window.hiveboxScene.snapshot()` 提供只读运行快照，用于检查阶段、8 人位置和渲染规模。

## 已验证

- 实际 8 人集合，全部就位后发射；连续两轮烟花流程与全员归位正常。

- 390 × 844 手机布局、圆盘移动、烟花流程；直接以 `file://` 打开离线 HTML，外部网络请求为 0。
