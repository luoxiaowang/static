# 归田小记

打开本目录的 `index.html` 即可游玩。三维引擎、模型、图标和界面已一起打包进 HTML，实时天气需要联网。使用支持 WebGL 2 的现代浏览器，允许本地存储。存档随浏览器和页面来源保存，切换域名、浏览器或文件位置后可能需要从头开始。

## 操作与生活节奏

- 点击地面或使用 WASD、方向键移动。点击地名会走到该地点互动，靠近后可点画面下方的互动按钮，或按 E。横拖画面可以转动镜头，滚轮和加减按钮可以缩放。按 M 打开地图，点图上的地名会自动步行，点列表里的「前往」可直接抵达。村路与石桥连接六处地点：归家小院、柳溪石桥、南山茶坞、禾香田埂、竹影山径和东门小集。禾场和竹林可协助村民做工换钱，集市可以直接交易。
- 快捷栏支持数字键 1–6。直接点田里的六块菜畦，林舟会走到畦边翻土、蹲下播种、浇水或收获。也可先在快捷栏指定农具，种袋支持青菜种和菊花种。点茶桌或院中茶席标记，林舟会走到凳边坐下饮茶。动作进行中可以走开，已完成的操作即时保存。在背包进入村口小铺买种子或卖出农产。
- 青菜需 90 秒，菊花需 150 秒，浇水可提前 35 秒收成。离线期间照常生长。体力每分钟恢复一点，茶和小憩可加快恢复。
- 邻里好感达到 40 可表白。好感达到 80、至少修屋一次并备有 60 文可成家。在老宅商量添丁后，现实一天后回家迎接孩子，可继续陪伴成长。
- 使用 Asia/Shanghai 时区。天气取黄山（29.71°N，118.34°E）的 Open-Meteo 天气、日出及日落资料，每 15 分钟请求一次。天气暂时不可用时保留一小时内的上次结果，随后显示未同步。缺少当日日照资料时使用北京时间的默认日出日落时刻。

## 扩展

在此目录运行 `npm install` 和 `npm run build` 生成单页。当前工作区也可复用已有的 Three.js 和 esbuild 依赖，运行 `node build.cjs`。

| 文件 | 修改内容 |
| --- | --- |
| src/world.js | 场景装配、地名标记、移动与过桥、行走边界、天气效果 |
| src/landscape.js | `places` 地点、`roads` 道路、桥面高度、石拱桥、花草和扩展村域的场景布置 |
| src/walking.js | 绕开建筑、沿河岸与桥头寻找可通行线路 |
| src/finishes.js | 住宅粉墙、夜间灯光、土路与路缘材质 |
| src/choreography.js | 田间与饮茶姿势、手持农具、茶盏和水滴 |
| src/villagers.js | 人物关节、面部、服饰染色与按移动距离驱动的步态 |
| src/game.js | 初始存档、背包、家庭阶段、商店价格、每日任务、种植逻辑与交互面板 |
| src/art.js | 中文界面使用的手绘工具图标、头像与线条图标 |
| src/page.html、src/style.css | 页面结构、游戏界面及手机布局 |

新增地点时，在 `places` 登记可通行的出生点，为地点建模并通过 `site` 设置互动位置。把互动编号加入 `game.js` 的面板及行为处理。新增存档字段时提供默认值，若修改嵌套字段结构，同时增加迁移处理。

三维引擎使用 Three.js（MIT），天气数据来自 [Open-Meteo](https://open-meteo.com/)。
