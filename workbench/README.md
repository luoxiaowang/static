# 我的工作台

一个可直接打开的静态个人工作台。Todo、倒计时、灵感、碎碎念、收藏夹和设置保存在当前浏览器的 IndexedDB 中；只有使用收藏 AI 识别或 Agent 助手时，相关 URL、问题与工作台上下文才会发送到 AgnesAI。

## 功能

- Todo 支持高、中、低优先级，以及当前日期/全部 Todo 视图；默认按未完成、优先级、到期时间排序。
- 本周倒计时按周一 00:00 到周五 24:00 计算，周末显示工作时间已结束。
- 番茄钟支持 30 分钟、1 小时、暂停、继续、重置和刷新恢复。
- 创意灵感与碎碎念按日期整理，并提供底部悬浮输入器。
- 收藏夹可调用 AgnesAI 识别 URL，生成标题、摘要和 Markdown 大纲；失败后可手动填写。
- Agent 助手基于当前工作台全部业务数据提供只读咨询，聊天记录刷新后清空。

## 直接打开

双击 `index.html` 即可运行，不需要安装依赖或启动服务。页面使用经典脚本包，因此不会受到 `file://` 禁止加载 ES Modules 的限制。

界面组件通过固定版本 CDN 加载，直接打开时需要联网。当前锁定 Vue `3.5.40`、Element Plus `2.14.3` 和 Element Plus Icons `2.3.2`。

AI 功能通过浏览器直接调用 AgnesAI。静态页面中的 API Key 可以被查看页面源码的人提取，不应将当前目录公开部署。部分浏览器或本地 `file://` 环境可能因跨域策略阻止 AI 请求；页面会显示错误，本地功能不受影响。

需要注意：不同浏览器对 `file://` 页面的 IndexedDB 隔离规则可能不同。移动目录、更换浏览器或以后改用静态服务器地址时，请先导出 JSON 备份，再通过新地址导入。

## 静态服务器运行

在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory workbench
```

然后访问 `http://127.0.0.1:4173`。

## 修改源码后重新生成脚本包

业务源码位于 `scripts/**/*.mjs`。修改后执行：

```bash
node workbench/build-bundle.mjs
```

这会更新 `scripts/app.bundle.js`，供直接打开和静态服务器共同使用。

## 数据说明

- 清理浏览器站点数据会删除工作台数据。
- 建议定期在“设置 → 数据管理”中导出 JSON 备份。
- 合并导入会按 ID 去重，相同 ID 使用导入文件中的记录。
- 覆盖还原前会自动下载当前数据备份。
- 新版备份包含收藏夹，并兼容导入缺少收藏夹的第一版备份。
- 浏览器关闭或电脑休眠时，静态页面无法保证倒计时通知准时到达。
- 浏览器通知授权状态以浏览器真实权限为准；授权成功后刷新页面仍显示已授权。
